This release makes root-request review readable for long commands and explanations, and requires explicit review before every pkexec/run0 request.

- Oversized commands and metadata use a bounded scrolling review; the subsequent password prompt stays compact.
- Polkit requests require review even with cached authentication. A pkexec-to-sudo fallback reuses approval for the same request; authentication denial never triggers fallback.
- A configured `confirm=always` cannot be downgraded by `AGENT_SUDO_CONFIRM=auth`.
- TSV log fields escape backslashes, tabs, newlines and carriage returns. Multiline reasons remain intact in the dialog; old log records are not rewritten.
- Clone installation creates missing skill directories for detected agents, supports explicit `--agent` selection, reports PATH/dependency requirements and refuses to replace existing real files/directories.
- Documentation distinguishes this repository's custom Claude Code marketplace from the official directory, where this plugin is not published.
- CI on Ubuntu 22.04 and 24.04 covers shell syntax, installer checks, 95 functional checks and 9 real Zenity geometry cases under Xvfb.

Compatibility: polkit users now get a review click on every request. Consumers of new TSV records should decode escaped field content. The tool remains an authentication helper, not an isolation boundary against processes running as the same user.

Update clone installations with `git pull --ff-only`; existing symlinks use the updated files. For skills CLI or custom marketplace installations, use that installer’s update mechanism and start a new agent session.
